Local-first by design

Your workspace stays on your computer.

PublishHarbor stores its working data locally and uses operating-system credential storage for supported provider credentials. Network access is used when you explicitly connect to social platforms, publish content, or use an optional provider feature.

PublishHarbor does not sell personal data. Provider integrations use the permissions needed to perform the actions you request. See the full Privacy Policy for details on OAuth, local storage and optional external services.
Simple on purpose

A practical tool, not another social network.

PublishHarbor is an independently developed desktop application. It does not host a public feed, profile network or advertising marketplace. The goal is simply to help creators manage their own publishing workflow.
